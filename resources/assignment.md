# Module 7: Programming Assignment 3

[Original in Canvas](https://canvas.northwestern.edu/courses/260285/assignments/1818439?module_item_id=3948252)

## **Overview**

This programming assignment builds on the two previous assignments. The goal is to write a program for automated, algorithmic trading and to backtest your trading strategy.

For this assignment, trading does not have to involve machine learning. Nor does it have to involve market regime detection. The minimum trading strategy for this assignment would be a simple mean-reversion or momentum model applied to the assets included in your fund's portfolio. Focus on automated trading itself.

Employ thorough backtesting of your approach. Employ metrics such as the Sharpe ratio to judge fund returns relative to their volatility. Evaluate your fund's performance against a buy-and-hold baseline benchmark with (1) the S&P 500 using [SPY ETF](https://www.etf.com/SPY), (2) a market-cap-weighted index of non-financial NASDAQ-listed stocks like [QQQ](https://www.etf.com/QQQ), or (3) a US Treasuries, aggregate bond, or fixed-income fund.

Use Clenow (2019) as a guide to get started on this assignment.

## **Instructions**

***This programming assignment should have its own unique, public Git Hub repository.*** Deliverables include a research report and Python program. The research report should be an Adobe Acrobat pdf file. The Python program can be (1) a Jupyter Notebook ipynb file and its associated html export, or (2) Python script py file with associated output listings and images. All deliverables should be submitted within a single public GitHub repository.

Grading Guidelines (50 points total)

* Problem Description (10 points)
* Data Preparation and Pipeline (10 points)
* Research Design (10 points)
* Programming (10 points)
* Exposition (10 points)

**Assignment Deliverables**

* Include the web address text (URL) for the GitHub repository in the comments form of the assignment posting. The web address you provide should be the URL for the cloneable GitHub repository. It should end with the .git extension.
* The Adobe pdf file for the report can be included in the repository.
* Files with the data being analyzed should be included in the repository.
* The README.md Markdown text file of the repository should provide complete documentation for the assignment. Include user instructions for running and testing the program. At the end of the README.md file, explain how you made use of AI assistants in completing the assignment.

Assignments in this class ask for documentation within public GitHub repositories. This link provides advice from Microsoft on writing good repo README files: [Create a README for your repo](https://learn.microsoft.com/en-us/azure/devops/repos/git/create-a-readme?view=azure-devops).
